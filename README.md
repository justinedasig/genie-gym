## 🌟 Features

* **Dynamic Exercise Tracker:** Mark individual daily exercises as completed, updating the Exercises Completed summary counter live.
* **Workout Split Customizer:** Drag-and-drop or select preset workout splits (PPL, Upper/Lower, Full Body).
* **Exercise Bank & Alternatives:** View, search, add, or remove custom exercises and view exercise alternatives.
* **Persisted Dark Mode Theme:** Toggle seamlessly between dark and light modes with automatic local storage persistence.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Framework:** Bootstrap 5.3 & Bootstrap Icons
* **Storage:** Web LocalStorage API (Client-side Data & Session Persistence)
